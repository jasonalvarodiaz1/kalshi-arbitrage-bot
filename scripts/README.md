# Scripts

Diagnostic and analysis scripts for the Kalshi Arbitrage Bot.

Run scripts from the repository root:
```bash
python scripts/<script_name>.py
```

## Script Reference

| Script | Description |
|--------|-------------|
| `analyze_results.py` | Analyze bot results and performance metrics |
| `analyze_trades.py` | Analyze executed trades and P&L |
| `auto_trade_crypto.py` | Auto-trading script for crypto markets |
| `check_binary.py` | Check binary market status and prices |
| `check_events.py` | Check event market listings |
| `check_forecast.py` | Check forecast/probability markets |
| `check_pnl.py` | Check current P&L from the database |
| `check_settle.py` | Check market settlement status |
| `check_settlements.py` | Bulk check of settlement outcomes |
| `check_status.py` | Check bot and API status |
| `convergence_diagnostic.py` | Diagnose convergence trading opportunities |
| `deep_pnl.py` | Deep P&L analysis with breakdowns |
| `diag_15m.py` | Diagnose 15-minute crypto interval markets |
| `diagnostic_scan.py` | Full diagnostic scan of all markets |
| `discover_weather.py` | Discover weather-related markets |
| `discover_weather2.py` | Alternative weather market discovery |
| `discover_weather_fast.py` | Fast weather market discovery (cached) |
| `ev_calc.py` | Expected value calculator |
| `scan_crypto_now.py` | Instant crypto market scan |
| `weather_deepdive.py` | Deep analysis of weather markets |
| `winrate_analysis.py` | Win rate analysis across strategies |
| `debug_orderbook.py` | Debug orderbook data for a ticker |
| `quick_scan.py` | Quick market scan utility |
| `test_notifications.py` | Test notification system |
